# Bazaar v2 — Full Modern Recreation Plan (with latest libraries)

## What was analyzed
**Bazaar v1.4.4** is a local-first Flutter shopping-list app (barcode scanning, 4-tier product lookup: Open Food Facts → SearXNG → Cloud LLM → on-device LLM, multi-store price tracking, encrypted ZIP backups, AR/EN + SAR/USD). ~12.3k hand-written lines, 64 Dart files, 7 SQLite tables, 20 screens.

Found problems: dead i18n layer (217 inline `isRtl` ternaries), N+1 queries, price-history data-loss bug (`REPLACE` on FK-targeted table), duplicate widgets, incomplete theming, Arabic item names never saved, blocking IO on UI thread, R8 disabled, ~140 lines of tests.

## Decisions
- **In-place rewrite on new branch `v2`** — keeps git history, CI, signing.
- **Design: "warm dark + gold souk"** — tokens from the project's own aspirational mockups (dark bg `#1A1815`, gold `#D6B85D`, text `#EEEEED`, success `#7BC393`, danger `#C47B74`; light bg `#F5F5F4`, gold `#8A7227`, text `#22211F`).
- **Full modern stack**: Riverpod, Drift (reactive SQLite, schema-v6 drop-in compatible), GoRouter, wired ARB l10n.
- **ALL libraries updated to latest versions**, adapting the code to any breaking API changes (mobile_scanner 7.x lifecycle, flutter_gemma 1.2.x, share_plus 13.x, file_picker 9.x, archive 4.x, etc.).

## Implementation steps
1. **Foundation**: branch `v2`; pubspec with all-latest versions + riverpod/drift/go_router; `pub upgrade --major-versions`; version 2.0.0+8; toolchain verified.
2. **Design system** (`lib/core/design/`): full M3 ColorScheme, typography (bundled Noto Sans + Arabic + mono), shared component library (AppCard, AppButton, PriceText, KpiCard, EmptyState, ConfirmDialog, QuantityStepper, SwipeToDelete, …) replacing all duplicated widgets.
3. **Drift data layer**: tables byte-mirroring schema v6 (same `bazaar.db` → seamless upgrade, no data loss); reactive `watch*` streams (kills manual refresh); JOIN queries fixing every N+1; cascade-bug fix; transactions for restore/import.
4. **Services port + harden**: scraper 4-tier pipeline (+cancellation), LLM extractor, on-device LLM, barcode, secrets, share (v2 JSON compat), backup (same AES-256-GCM wire format; moved to `Isolate.run`; adds categories + price history).
5. **Wiring**: Riverpod providers, GoRouter shell routes, share-intent bootstrap; ARB expanded ~49 → ~250 keys ×2 languages; zero inline `isRtl` ternaries.
6. **UI rebuild** — all 20 screens on the new design system (home dashboard, items, add/edit item with Arabic-name fix, scanner, list detail decomposed from 1007 lines, stores, settings, LLM settings, pipeline debugger, categories), with hero animations and `ListView.builder` everywhere.
7. **Security & quality**: R8 + proguard rules; SECURITY.md invariants kept; honest HTTPS story; tests (DAO in-memory, backup crypto round-trip incl. encrypted, import validation, widget smoke); CI gains build_runner step.
8. **Bilingual README.md** — single file, full English + Arabic sections.
9. **Verify**: `flutter analyze` clean, `flutter test` green, `flutter build apk --release`; all committed on `v2`.
